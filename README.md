# AI Shopping Buddy

## Project Overview
AI Shopping Buddy is a mini project developed using Python that helps users find products based on their requirements and budget.

The system acts as a simple shopping assistant and recommends suitable products from a product database.

## Features
- Product recommendations based on budget
- Category-based product search
- Simple user-friendly interface
- Fast product filtering
- Basic AI/NLP-based query understanding

## Technologies Used
- Python
- Streamlit
- Pandas
- CSV Dataset

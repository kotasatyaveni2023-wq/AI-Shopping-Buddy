# AI-Shopping-Buddy
An AI-powered shopping assistant that helps users find suitable products based on their preferences, budget, and category. Built using Python, Streamlit, and basic NLP techniques
Project Overview
AI Shopping Buddy is a mini project developed using Python that helps users find products based on their requirements and budget. The system acts as a simple shopping assistant and recommends suitable products from a product database.
Features
Product recommendations based on budget
Category-based product search
Simple user-friendly interface
Fast product filtering
Basic AI/NLP-based query understanding
Technologies Used
Python
Streamlit
Pandas
CSV Dataset
Project Structure
AI_Shopping_Buddy/ ├── app.py ├── products.csv ├── requirements.txt └── README.md
How to Run
Install required libraries: pip install streamlit pandas
Run the application: streamlit run app.py

I need a mobile
Budget: 20000
